训练模式

泄漏物质

泄漏物质与泄漏形式一样，每局由种子随机决定，开局不公布、不可自选。先靠现场确认、pH 试纸与运单核对查明物质，再作易燃／腐蚀性判定与后续处置。物质参数为本情景设定值，非厂内标准；实际应变以厂内 SDS 与现行文件为准。

随机种子

同种子 + 同操作顺序，结果可复现；化学品局的泄漏形式与物质也由种子决定，同种子同形式、同物质，开局均不公布。

评分权重设置（系统内配置）

每项须为 0–100 的整数，合计须为 100%。设置用于后续各局的复盘总分。

本系统为训练仿真，与真实 GMS / FPS / FAC 系统完全隔离；监控读值为仿真数据。

操作说明

你怎么指挥这一局

  1. 看态势：「态势」页是事故区域平面图，点设备（泄漏源、GMS、CCTV、雨水沟等）弹出详情与可下达的指令。化学品局的泄漏形式与泄漏物质每局随机，开局通报只给区域与现象：形式与确切位置要靠 CCTV、现场回报与侦测器定位逐步确认；物质要靠现场确认后追问 pH 试纸与运单核对查明，查明前顶栏只显示「物质 未确认」，易燃／腐蚀性判定在查明物质后才开放。
  2. 接通讯：「通讯」页有来电与回报。来电响铃时先接听；回报不完整时点「追问」补全。
  3. 下指令：「调度」页按单位列出可下达的指令与在办任务。条件未齐的指令会写明还缺什么，先补齐再下达。
  4. 作指挥决策：没有答题卡。需要你拍板的事，都做成现场指挥动作，在它们所在的位置完成——
    • 定等级：「态势」页指挥区的等级控件（顶栏同步显示当前等级），拨到对应档位后按「确认等级」。
    • 定策略：「调度」页顶部的策略区，按当前局面选定应变策略后按「执行策略」。
    • 圈管制范围：「态势」页指挥区的管制范围控件，在态势图上选范围档位（仅热区 / 热区+暖区 / 含外围道路）后按「执行管制」。
    • 升级通报：「通讯」页顶部的升级通报区——通报动作本身就是决策，选定通报对象与是否升级后发出。
    • 申请解除：现场受控后，在「态势」页指挥区发起解除申请，系统按核准条件逐项核对，齐备才核准、缺项即驳回并说明。
    「态势」页下方的证据与后果区只展示你已掌握的证据、各选择将带来的分支后果，不在那里作答；决定一律由上面的指挥动作触发，选错会按所选分支真实推进事故。
  5. 盯读值：「监控」页看 GMS 读值与趋势；「记录」页看全程事件与你的每项决策。
  6. 不知道下一步？教学局顶部常驻「下一步指引」：写明当前阶段目标、下一步去哪个控件做、正在等谁的回报，还能展开阶段清单看全程走到哪一段。指引只教操作，不替你作决策；考核局不显示指引，也没有证据量表与即时对错反馈。

事故不会等你：不操作时泄漏、积液与读值仍会演变。可以暂停或切换 1x / 2x 倍速。进入热区、疏散广播等高风险操作需要两步确认。

八局决策地基（各自原图）

  • 化学品泄漏：化学品作业区泄漏，泄漏形式（槽车卸料 / 管线法兰 / 泵浦密封 / 储槽本体 / 桶槽倾倒 / 废液系统）与泄漏物质（氢氟酸 / 硫酸 / 异丙醇）每局均由种子随机决定、开局不公布，靠取证逐步确认，化学品泄漏处理流程原图（60 环节 / 62 连线）。
  • 气体泄漏：GMS 两段报警（Hi / HiHi）与便携侦测器现场确认，气体泄漏处理流程原图（47 / 51）。
  • 火灾：VESDA / FPS 报警定位、灭火与疏散、火势可复燃，火灾处理流程原图（58 / 63）。
  • 电力中断 / 压降：压降与全停电两种起局，复电程序按原图顺序推进，电力中断或压降处理流程原图（26 / 30）。
  • 漏水：多点位排查定位、关阀隔离、机台与晶圆防护，漏水处理流程原图（22 / 23）。
  • 地震：震度参数起局、震后巡检与次生灾害排查、余震注入，地震处理流程原图（24 / 26）。
  • 异味：多点位量测溯源，真泄漏与误报两分支均可达，异味处理流程原图（21 / 23）。
  • 紧急应变指挥官：IC 视角指挥局，压在化学品或气体事故之上，升级、交接与外部支援时机为核心决策，紧急应变指挥官处理流程原图（37 / 41）。

  • 地图缩放为按钮 + 拖动平移实现；双指手势在部分内置浏览器中由系统手势接管时，可用按钮缩放替代。
